## ⚠️ Problema Descoberto — BLOQUEANTE

### Issue: Dados com Encoding Quebrado no Supabase

**Descoberta**: XLSX exportado mostra `Jo?o` e `3?` em vez de `João` e `3º`

**Diagnóstico**:
- Extraiu XLSX e analisou `sharedStrings.xml` (XML interno do XLSX)
- XML contém Unicode replacement character `\ufffd` em vez dos acentos reais
- **Conclusão**: Dados já estão **salvos errado no Supabase**, não é problema do export

**Evidência**:
```
Esperado: <si><t>João Silva Santos</t></si>
Encontrado: <si><t>Jo\ufffdSilva Santos</t></si>
```

**Quando aconteceu**:
- Provavelmente quando respostas foram **salvas no `/api/surveys/[slug]/submit`**
- Ou quando dados foram **importados/migrados** de outro lugar

**Verificação necessária**: Ir em `/admin/surveys/{id}/responses` e verificar:
- Se nomes aparecem corretos na tabela → problema é só na export
- Se nomes já estão quebrados lá → problema é no Supabase (dados salvos errado)
