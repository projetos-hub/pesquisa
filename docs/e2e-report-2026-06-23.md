## Bug Encontrado e Corrigido

`SurveyRunner` ficava preso no loading quando a API de survey retornava 403, porque o render checava loading antes de `accessDenied`.

Correcoes:
- `SurveyRunner.tsx`: renderiza `AccessDeniedCard` antes do fallback de loading.
- `useSurveyBootstrap.ts`: propaga `email` vindo da URL quando o Layers Hub nao fornece perfil.
